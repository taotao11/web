# 乱世赵匡胤：黄袍之前

HTML5 interactive historical fiction prototype.

- Historical spine: Late Later Han / Later Zhou / Five Dynasties transition
- Player: Zhao Kuangyin
- Experience: narrative-led branching story
- Saves: localStorage, 3 manual slots + autosave
- First vertical slice: the starving frontier camp
- Static deployment friendly: GitHub Pages / Cloudflare Pages / Vercel

## Run

Open `index.html` directly, or deploy this repository as a static site.

## Design principles

Historical events are used as anchors; private dialogue, many side characters, and alternate outcomes are original game fiction. The game does not present invented dialogue as historical quotation.

The prototype deliberately uses hidden causal variables instead of a conventional RPG stat panel. Choices alter later scenes and relationships.
